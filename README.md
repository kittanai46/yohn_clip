# Yohn Clip (Android)

แอปสำหรับรวบรวมคลิปวิดีโอที่กระจายอยู่หลายโฟลเดอร์ในมือถือ มาไว้โฟลเดอร์เดียว
เพื่อเสียบ USB แล้วลากไป PC ทีเดียว พร้อมจำว่าไฟล์ไหนเคยส่งไปแล้ว

## ทำอะไรได้
- **สแกนวิดีโอทั้งเครื่อง** ผ่าน MediaStore ไม่ต้องไล่เข้าโฟลเดอร์เอง
- **แยก 3 กลุ่ม**: อัดจอเกม / กล้อง / อื่นๆ (ดูจากโฟลเดอร์ → ชื่อไฟล์ → สัดส่วนภาพ)
- **จัดกลุ่มตามวัน** พร้อมบอกจำนวนที่ยังไม่ส่งและขนาดรวม
- **สถานะ ส่งแล้ว / ยังไม่ส่ง** และปุ่ม "เลือกที่ยังไม่ส่งทั้งหมด"
- **จัดเตรียมส่ง USB**: คัดลอกไฟล์ที่เลือกไป `Movies/GameExport/<วันที่>/`
  และเปลี่ยนชื่อเป็น `ชื่อเกม_2026-11-05_14-32-10.mp4` เรียงบน PC ง่าย
- **จำว่าส่งแล้ว** ด้วย Room (key = id + ขนาด + เวลาแก้ไข ทนต่อชื่อซ้ำ/ย้ายโฟลเดอร์)
- **mark ด้วยมือ** ส่งแล้ว / ยังไม่ส่ง (ปุ่ม ✓ และ ↶ ด้านล่าง)
- **เคลียร์โฟลเดอร์ Export** หลังคัดลอกไป PC เสร็จ (ต้นฉบับไม่ถูกลบ)

## วิธีใช้
1. เปิดแอป → อนุญาตสิทธิ์อ่านวิดีโอ → แอปสแกนให้อัตโนมัติ
2. เลือกแท็บ "อัดจอเกม" → กด "เลือกที่ยังไม่ส่งทั้งหมด" → กด "จัดเตรียมส่ง USB"
3. เสียบ USB (โหมด File transfer / MTP) → บน PC เปิด `Internal storage/Movies/GameExport/`
   → ลากโฟลเดอร์วันนั้นไป PC
4. กลับมาที่แอป → กดไอคอนถังขยะ เพื่อลบไฟล์ใน Export คืนพื้นที่

## Build
- Android Studio Koala (2024.1) ขึ้นไป, JDK 17
- เปิดโฟลเดอร์นี้ → Sync Gradle → Run
- ถ้า Android Studio ถามเรื่อง Gradle wrapper ให้เลือกสร้าง (ใช้ Gradle 8.7+)
- minSdk 29 (Android 10+)

## โครงสร้าง
```
app/src/main/java/th/yohnclip/
├── App.kt                 # ตั้งค่า Coil ให้ถอด thumbnail วิดีโอ
├── MainActivity.kt        # ขอ permission + แสดง MainScreen
├── data/
│   ├── Models.kt          # VideoItem, VideoSource, fingerprint
│   ├── SourceClassifier.kt# กฎแยก เกม/กล้อง/อื่นๆ  ← ปรับคำได้ที่นี่
│   ├── VideoScanner.kt    # query MediaStore
│   ├── Db.kt              # Room: ตาราง sent_files
│   └── Exporter.kt        # copy ไป Movies/GameExport ผ่าน MediaStore
└── ui/
    ├── MainViewModel.kt   # state + logic
    └── MainScreen.kt      # Compose UI
```

## ปรับการแยกเกม/กล้อง
แก้ที่ `SourceClassifier.kt`
- `gameDirs` — ชื่อโฟลเดอร์ของแอปอัดจอ/เกมที่คุณใช้ (เช่น ยี่ห้อมือถือ: Samsung = `DCIM/Screen recordings`, Xiaomi = `DCIM/ScreenRecorder`)
- `cameraDirs` — โฟลเดอร์กล้อง
- ถ้าไฟล์ไหนแยกผิด ให้ดู path ตัวเล็กใต้ชื่อไฟล์ในแอป แล้วเพิ่มคำลง list

## ข้อควรรู้
- การ "จัดเตรียม" เป็นการ **คัดลอก** (ไม่ใช่ย้าย) จึงใช้พื้นที่ชั่วคราวเท่าขนาดไฟล์ที่เลือก
  ลบได้หลังส่งเสร็จด้วยปุ่มถังขยะ
- ถ้า PC ยังไม่เห็นไฟล์ใหม่ ให้ถอด-เสียบ USB ใหม่ หรือเลือกโหมด USB เป็น "File transfer" อีกครั้ง
- เอาไฟล์ Export ไปแล้ว อยากลบต้นฉบับด้วย ทำได้ในแอปแกลเลอรี่ (เวอร์ชันนี้ยังไม่ลบต้นฉบับให้ เพื่อความปลอดภัย)
